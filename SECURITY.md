## Security Policy

### Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

### Reporting a Vulnerability

If you discover a security vulnerability, please report it by emailing **553807266@qq.com**.

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

We will respond within 48 hours and work on a fix promptly.
